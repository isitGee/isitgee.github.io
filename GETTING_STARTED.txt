📊 HOW IT WORKS
═══════════════════════════════════════════════════════════════

User Submits Form
     ↓
Script.js validates inputs
     ↓
Sends POST to /api/contact
     ↓

     ↓
Returns success response
     ↓
Form clears, user sees "Message sent!" ✓

Admin Accesses Dashboard
     ↓
Logs in with admin token
     ↓
Dashboard calls GET /api/messages
     ↓
Backend returns all messages
     ↓
Admin sees beautiful dashboard with all contacts

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════

Q: Where do messages get stored?
A: In backend/data/messages.json (simple JSON file)
   No database needed! Easy to backup.

Q: Can I change the admin token?
A: Yes, edit backend/data/admin-config.json
   Restart server: npm start

Q: Can I deploy without changing token?
A: ⚠️  NO! Change admin token BEFORE deployment!
   (Setup.sh already did this for you)

Q: How do I backup messages?
A: Download backend/data/messages.json
   It's just a JSON file - easy to backup!

Q: Can I add more fields to contact form?
A: Yes! Full instructions in backend/README.md
   Requires changes to HTML, script.js, and server.js

Q: How do I get email notifications?
A: Add Nodemailer integration (see CUSTOMIZATION section)
   Takes 10-15 minutes to set up

Q: Can I use a real database instead of JSON?
A: Yes! Replace JSON with MongoDB/PostgreSQL
   Instructions in backend/README.md

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Backend won't start
  → Check Node.js: node --version (need 14+)
  → Check port: lsof -i :3000 (or use PORT=3001 npm start)
  → Reinstall: rm -rf node_modules && npm install

Admin dashboard won't load
  → Verify backend running: npm start shows no errors
  → Check URL: http://localhost:3000/admin
  → Clear cache: Ctrl+Shift+Del (or Cmd+Shift+Del)

Form won't submit
  → Open DevTools: F12
  → Check Console for errors
  → Verify backend running
  → Check network tab to see the request

Messages not saving
  → Check backend logs: npm start (look for errors)
  → Verify backend/data/ directory exists
  → Check disk space available

Can't remember admin token
  → Check: backend/data/admin-config.json
  → Or regenerate: bash setup.sh (generates new one)
