🎯 HOW TO GET STARTED
════════════════════════════════════════════════════════════════

FASTEST WAY (Copy & Paste):

  cd backend
  npm install
  bash setup.sh
  npm start

Then visit: http://localhost:3000/admin

DETAILED STEPS:

  1. Navigate to backend:
     $ cd backend

  2. Install dependencies:
     $ npm install
     (Downloads Express, CORS, body-parser)

  3. Generate admin token:
     $ bash setup.sh
     (Creates secure token and configuration)

  4. Start the server:
     $ npm start
     (Server runs on http://localhost:3000)

  5. Access admin dashboard:
     → Open browser to http://localhost:3000/admin
     → Login with admin token (shown during setup.sh)
     → Start managing messages!

  6. Test the contact form:
     → Go to your portfolio website
     → Fill out contact form
     → Submit message
     → Check admin dashboard - message appears! ✓

🆘 QUICK TROUBLESHOOTING
════════════════════════════════════════════════════════════════

PROBLEM: "npm: command not found"
SOLUTION:
  - Install Node.js from nodejs.org
  - Restart terminal
  - Verify: node --version && npm --version

PROBLEM: "npm install fails"
SOLUTION:
  - Delete node_modules: rm -rf node_modules
  - Delete package-lock.json: rm package-lock.json
  - Try again: npm install

PROBLEM: "Port 3000 already in use"
SOLUTION:
  - Use different port: PORT=3001 npm start
  - Or kill process: lsof -i :3000 | grep node | awk '{print $2}' | xargs kill

PROBLEM: "Admin dashboard won't load"
SOLUTION:
  - Verify backend running: npm start (no errors)
  - Check URL: http://localhost:3000 (should work)
  - Clear cache: Ctrl+Shift+Del (or Cmd+Shift+Del)
  - Try incognito window

PROBLEM: "Admin login won't work"
SOLUTION:
  - Check token in backend/data/admin-config.json
  - Verify you're using the correct token
  - Try clearing localStorage in browser (F12)
  - Regenerate token: bash setup.sh

PROBLEM: "Form won't submit"
SOLUTION:
  - Open browser DevTools: F12
  - Check Console tab for errors
  - Check Network tab to see if request is sent
  - Verify backend is running
  - Verify frontend API_URL is correct

PROBLEM: "Message doesn't appear in dashboard"
SOLUTION:
  - Check backend logs (npm start terminal)
  - Verify form actually submits (check Network tab)
  - Check backend/data/messages.json exists
  - Refresh dashboard: F5
  - Try submitting another message
